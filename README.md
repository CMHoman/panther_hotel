# Panther Hotel Assignment

A prototype hotel reservation website built with Python and Flask

# Description

This allows guests to book hotel rooms and managers to view all the reservations. Built using Flask for the bacekend, bootstrap for the frontend, and SQLite as the database.

# Features

- Welcome page
- Room reservations form
- Confirmation page displayed after booking room
- Manager page showing all reservations

# How to run

1. Clone repository
2. Create and activate the virtual environment:
python3 -m venv venv
source venv/bin/activate
3. Install the dependencies:
pip install -r requirements.txt
4. Run the application:
python3 app.py
5. Open your browser and go to:
http://127.0.0.1:5000
